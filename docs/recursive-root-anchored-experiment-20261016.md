# R1：根锚定递归对照实验预注册

日期：2026-10-16。用户已授权保留递归思想、修改实现并新增一个实验。本次只新增组 `R1-root-anchored-recursive`，variant 为 `root_anchored_recursive`，独立 fresh 训练 150 个 outer；复用本任务已有 A（`original`）和 C1（`C1-root-only`）的同轮结果，不重跑或覆盖这些对照。

本文件冻结科学设计、比较终点和解释边界。文档、代码提交或作业提交不代表实验已启动、机制已验收或结果已改善；实际源码、配置、初始化、数据、硬件、运行身份及完成状态另存不可变票据。参照是本次重建的 A/C1，不以作者历史运行或另一硬件上的历史分数替代。

## 假设与两个机制变化

假设：在固定十次续写预算内，让已接纳子轨迹继续提供新的采样前缀，可能改善根轨迹的奖励对照；相对当前父节点强制翻转奖励，以及按所有更低代历史限制分叉位置，可能妨碍这种作用。这是待检验假设，不预设 R1 的最终 EM 必须更高。

相对 A，仅改变以下两项：

1. **接纳参照固定为初始根。**完整子轨迹满足 `child.reward != initial_root.reward` 才进入接纳集合；满足 `child.reward == initial_root.reward` 则进入候选补齐池。父节点仍从当前有合法分叉位置的接纳轨迹中均匀选择，包含根和真实子代。因此子轨迹可以与其直接父节点奖励相同而被接纳；禁止偷偷恢复为相对父节点判断。
2. **取消 generation 全历史 LCP 下界。**对选中的父轨迹，从其全部合法行动前 executor snapshot 中均匀选择起点；同父逐步向前回退，最早可到该轨迹的第一个合法行动前状态。保持真实状态合法性过滤，不允许在任意 token 或文本字符处切分。不再因为低代历史的共同前缀而额外缩小合法位置集合。

其他选择规则不变：无根偏置、无深度偏置、无额外候选排序、无新增文本去重、无强制深代采样。`generation` 仍为 `parent.generation + 1`，根为 0；不能修改谱系标签制造递归。

## 每题执行合同

1. 用当前策略生成一条完整初始根，严格最终答案奖励为 0 或 1。根放入接纳集合并始终保留；最终目标五条**包含根**。
2. 根生成不计入续写预算。每题最多十次实际 continuation 尝试，回退续写同样计次；不因不足、错误或评测表现追加预算。
3. 均匀选择具有合法行动前状态的已接纳父轨迹，按上述规则确定起点，从真实 snapshot 续写。完整继承已有 action token、observation、行为概率、已使用 turn/search 预算；不能给子代重新分配完整的交互轮数。
4. 相对根的异奖励子轨迹被接纳，并可在后续搜索中作父；相对根同奖励子轨迹进入补齐池，并按原同父回退流程继续。接纳成功后结束本次同父搜索，后续重新选择父轨迹。
5. 接纳集合达到五条、预算耗尽或无可扩展轨迹时终止。若不足五条，从同根奖励的真实完整候选池均匀、无放回补齐至目标或池耗尽；不重复 ID、不伪造轨迹、不额外 rollout。错误及未完成执行不能作为奖励 0 的候选，沿用原拒绝和故障处理路径。

根奖励为 0 时优先接纳奖励 1 的子轨迹；根奖励为 1 时优先接纳奖励 0 的子轨迹，因此这不是“只保留成功轨迹”。若找到四条异根奖励轨迹，最终组为 1:4 的两类奖励组成；预算内未找齐时允许同根奖励补齐，不能宣称每题必有对比或固定 1:4。

相对 C1，上述接纳参照和合法位置规则在根父节点上完全一致：C1 的父只能是根，根的原 generation-LCP 下界自然为 0。R1 与 C1 的有效采样区别是是否允许已接纳的非根轨迹继续作父。相对 A 则同时改变两个机制，不能把 R1 对 A 的差异分别归因于其中任何一个。

## 预先固定的结果判断

- **主要比较：150 轮 R1 对 C1 的固定 dev512 汇总 EM 差值。**正、零、负差值均如实报告，不以达到正差值作为运行或验收条件。
- **次要比较：150 轮 R1 对本次 A 的同轮汇总 EM。**不得用 A200 对 R1 150，亦不得以其他历史运行替代本次 A。
- 100 轮是辅助的同轮比较；50 轮是探索性中期结果；5 轮主要用于确认运行与机制。上述节点不改变主要终点，不构成多次尝试后选择一次胜出的规则。
- 不挑选 best checkpoint，不用 TRAIN/cohort 正确率、混合奖励比例或优势方差替代 dev EM；不在看到中期结果后调整父选择、位置、接纳规则、预算、loss 或超参数。
- 运行报告保留全部预定节点，包括负结果、零差异和未显著结果。单 seed、512 道评测题以及方法设计已经参考过同一 dev 的事实，限制结论外推；点估计领先不等于跨 seed 稳定收益或独立测试集上的确证。
- 原始按题评测输出随原有评测流程保留；汇总报告沿用已有评测合同，不为此组临时新增测试集、重复生成、显著性门槛或以统计结果触发再次调参。

若 R1 在主要终点优于 C1，只能支持“在本次根锚定筛选、无代际 LCP 限制及固定训练设置下，允许已接纳子代继续作父可能有价值”。这不能证明原版 A 的递归策略有效、树越深越好、所有递归方法优越，也不能直接证明优于原论文 Tree-GRPO/BranPO。若没有优于 C1，该负结果保留，不能改称机制成功或将研究主张转移到未预注册的最好节点。

## 机制验收与诊断

实现检查与实际运行证据分开：测试通过只说明代码覆盖了预定行为，不能替代真实生成事件。前五轮验收应核对有限 loss、真实 Adam 写入、保存/恢复身份和后续轮次产物；五轮不是停止预算，也不因等待人工认可而自动暂停。

每个真实分叉事件至少区分：根 ID 与奖励、直接父 ID/奖励/generation、子 ID/奖励/generation、实际分叉位置、接纳参照为根、相对根是否异奖励、相对父是否同奖励、进入接纳集或补齐池的原因，以及实际续写预算消耗。不得将“与父同奖励但与根异奖励”的合法接纳标为原 A 的拒绝或错误。

递归证据分两个层次报告：

1. **谱系递归：**实际使用非根父节点并产生 generation 至少为 2 的完整子轨迹。应报告计数和占比；只允许自然发生，不能为达验收指标强制选择非根父、增加预算或追加采样。若未发生，报告“本次尚未实际观察到递归扩展”，不冒称已验证递归效果。
2. **有效前缀递归：**非根父提供给本次续写的实际继承前缀，必须保留至少一个相对初始根新增或不同的模型行动，且对应观测与真实 snapshot 一起保留。应比较实际行动内容及位置，不能只凭 parent ID 或 `generation > 1` 判断；从子轨迹分叉却在保留任何新行动之前就回退，只有谱系标签递归，不计入该指标。行动相同而仅观测不同的情况另记，不能混入“新行动”计数。

上述有效前缀指标仅为被动记录与审计，不参与父选择、起点分布、接纳或停止。报告其分母（非根父续写数及全部续写数）、计数和比例，并保留足以复核的行动前缀证据。若 generation 2 自然出现但有效前缀计数为零，必须明确这一限制。

独立只读机制入口为 `python -m reproduction.recursive_lumia.r1_evidence --receipt <R1配置票据> --outer 5 --output <新的审计JSON路径>`；outer 可为5/50/100/150，输出文件已存在则拒绝覆盖。该工具检查配置哈希、同轮512题事件身份、根相对接纳和预算、实际候选及snapshot，并从保存的 `state.raw_ledger` 独立重算新行动/观测差异与前缀哈希。零有效递归是合法统计结果；稀疏记录节点不能冒充全部训练轮次的总体分母。原有研究批次汇总、C1/C2完成门禁和 `planned_conditions()` 不纳入 R1；R1 使用此独立机制审计，评测比较复用已有按路径同轮比较工具，不另建评测器。

该离线机制审计核对 snapshot 文件哈希、谱系身份及 raw-ledger 前缀，不独立重演全部 executor 状态字段、模型概率、答案评分或优化器消费；不能替代原在线状态继承检查与训练/原生存档验收。

其他诊断沿用必要小型聚合：每题候选、接纳、补齐与最终训练条数，未满五条比例，实际 generation、分叉位置、混合/全正确/全错误题比例，实际 token 与检索成本。混合奖励题比例或奖励平衡本身不能证明更优；单根标准化优势不等于新增了节点级信用分配。

## 成本、故障与完成边界

相同 outer、目标五条和预算十次不代表相同计算量。分别报告累计实际 continuation 尝试、生成/保留/丢弃 token、prefill token、检索量、最终训练轨迹与有效 token 曝光、真实 Adam 提交和 GPU 小时；废弃尝试、重跑和迁移成本保留，不从历史总账抹去。硬件不同时，不能仅以 GPU 小时断言算法计算效率更高。

正常运行持续到 150 个完整 outer，不因中期 EM 低于 A/C1、负差值或未达到预想效果而提前停止。科学配置/身份错误、执行或数值故障、资源/存储故障按既有安全合同处理；保存可恢复状态、保留故障证据，修复后从经验证的完整状态继续，不以 fresh 重跑冒充续训。用户后续明确变更授权时遵从并记录。

完成声明需要真实训练账、150 节点评测与关键状态保存证据。没有这些证据时只报告实际已完成部分。新增实验不自动授权其他 variant、多 seed 扩展或 51,713 题最终集评测，也不热改正在运行的 A/C1。
