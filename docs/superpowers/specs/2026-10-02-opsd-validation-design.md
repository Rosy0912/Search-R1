# OPSD validation observability

Authorized scope: PLAN sections 3/5/7 and agent 4 handoff require separate F1, EM, format, generated tokens, search calls, teacher CPU/RAM and real 3B acceptance. The existing user instruction executes this reviewed plan. This change supplies those observations without changing training targets, reward, sampling, masks, model, data, batch or update budget.

Alternatives: retain scalar QA EM and infer missing metrics from logs (insufficient); add an independent second generation pass (extra cost and different samples); measure the existing validation trajectories (selected, implemented centrally by the common-setup owner; OPSD reuses that shared commit rather than duplicating its evaluator). Reuse model-only spans separated at retrieval boundaries, so prompt/observation answers cannot earn score. F1 is normalized token F1 maximized across accepted answers; EM retains the existing QA scorer; format rate means a complete answer tag exists wholly inside model-authored text. Failed/unanswered rows score zero. Report per-source means over all rows, preserving raw existing score and count. Generated token counts exclude observations/padding; search counts come from existing trajectory metadata. These additions must also be used for the eventual GRPO comparison.

Teacher timing covers loading and CPU forward/output projection intervals, recording process CPU seconds and wall seconds separately. CPU projection timing excludes CPU-to-student-CUDA transfers and their potential stream waits. Process CPU time sums all worker CPU threads active during the measured interval; it is not exclusive profiler attribution. Report exact frozen model tensor bytes, and the actor process high-water RSS separately: worker RSS includes student/optimizer and must not be described as isolated teacher RAM. No extra inference is performed.

Verification: adversarial observations/prompt answers, tags split across observation boundaries, multiple accepted answers, zero-generation rows, uneven source/batch aggregation; existing real tiny teacher/student test plus independent reviewer checks. Real 3B/FSDP smoke, checkpoint reload and full evaluation remain mandatory and cannot be replaced by these CPU probes.
