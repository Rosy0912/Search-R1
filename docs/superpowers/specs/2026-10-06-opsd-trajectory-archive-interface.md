# Paired diagnostic archive interface

Approved scope: the fresh `multitraj200` experiment. Old profiles do not instantiate the recorder and do not enable raw-turn capture. Diagnostics never supply loss targets, student prompts, rewards, or evaluation inputs.

The driver extracts the 512 unique source question IDs and original common-data rows before `DataProto.repeat`. Every question keeps its original outer position. Repetition adds explicit response index 0..4 and source/group identity; all 2560 completed student records are saved before balancing, with exact prompt/response/input token IDs, attention/info/derived loss masks, positions and real raw tool turns. Original generation context, padded raw output and postprocessed action are distinct fields; untruncated observation text/tokens and retained observation tokens are both stored. Before the actual actor update the reordered batch is checked against its archived row digests and actual loss masks.

`data.meta_info['opsd_trajectory_archive']` carries the same complete immutable question request to every worker. The actor hook inside the already existing `teacher.on_device()` context, before `_update_policy`, calls `generate_rank_teacher_diagnostics(teacher, data, tokenizer)`. Global rank r handles original question positions 64r..64r+63. This assignment does not depend on balanced student rows. Real `teacher.model.generate` uses the official template, explicitly recorded privileged training answers, a diagnostic-only concise-answer instruction, greedy decoding, at most 128 new tokens and no KV cache. It is a short independent answer diagnostic, not a complete teacher search trajectory or a fair no-gold accuracy comparison.

Python, NumPy, Torch CPU and only the current CUDA generator are saved and restored. The model's registered buffers, nonpersistent buffer sets, generation/model configuration, module training flags and RoPE/cache attributes are protected and checked as well. Frozen parameter identity/version is checked; this is not a repeated full 3B-weight hash. Teacher q remains evaluated on the actual student history after restoration. Diagnostic token/time intervals are reported separately and are already included in teacher cumulative timing, so costs must not be added twice. The driver reads all eight rank reports for authoritative diagnostic cost totals because `DataProto.concat` preserves rank0 metadata. No optimizer or scheduler call is introduced, and the existing one teacher device entry per outer is preserved.

Each outer is an exclusive physical owned directory. Its question request and student JSONL/manifest are durable immutable members. Each rank exclusively publishes its teacher JSONL and manifest. After all actor workers return, the driver reads and verifies all eight rank files and publishes a paired final manifest containing actual SHA256/counts/identities. Failed attempts leave their partial originals, are not overwritten, and cannot be called complete. Final manifest availability is a functional archive gate, not evidence of a beneficial effect.

Exactly twenty immutable members exist per completed outer. `checkpoint_inventory(step)` returns role-to-path/SHA records for all completed outers; at first5 this is exactly 100 members in the actual training manifest. Algorithm state stores only the completed outer and last paired manifest identity. `validate_checkpoint_archives(manifest, runroot, verified_official_tokenizer)` rereads every raw archive, joins native eight distinct worker PIDs, and binds source/job/driver/config and teacher path to the actual resolved configuration. It replays official chat templates, generated text/token relations, exact teacher inputs, and actual student tool-turn histories, retained response masks and step IDs. Without an external worker map, generic `validate_archive` reports content-only scope and cannot establish actual GPU provenance. Ray worker local CUDA indices may differ from global rank; physical UUID ownership is independently checked by native resource evidence.

CPU tests exercise real tensor/row identity, reordered-batch joins, exact masks, duplicate and missing groups, exclusive/no-symlink persistence, all RNG restoration after normal and exceptional generation, model buffer/cache/config restoration and true generate output provenance. CPU toy generation cannot satisfy the actual same-node GPU/frozen-official-teacher gate.
