# M 组十轮的逐 token 记录核验

M 组已实际完成十个在线采样/训练轮次，100 次 Adam 更新、3032 条可用配对及 637380 个有效 policy token。对已持久备份的原始训练记录进行独立 CPU 汇总，未重新运行模型、生成、评分或训练；三个只读分析入口实际返回码均为 0。

在全部十轮的已提交有效 token 上，反向 KL 词表分量超过上限 10 的次数为 0，被裁剪集合上的 student、teacher 和 mixture 概率质量均为 0，记录的裁剪前后损失相等。这支持“上限 10 在本次 M 组已提交记录中没有触发”，不能据此判定上限对其他组无影响。每轨迹先平均再等轨迹平均的损失为 0.0065818880；把全部 token 混在一起平均为 0.0060247529，后者不是本实验的优化分母。

M 的目标分布是 0.1 teacher + 0.9 冻结的本轮旧学生。较小的目标 KL 不代表对教师的 KL 更小，也不能代替自主 512 题 EM。该组全量 512 题评测仍在原八卡队列执行中，本文不报告部分题目的 EM。

调试资产已保存并逐成员 SHA 核对：25600 条学生轨迹、80 份生成记录、80 份 HTTP 检索记录，以及 80 个独立特权教师自主生成案例（每轮 CC/CW 各四个）。有效 token 的标量记录覆盖 637380 个位置；其中 81920 个位置保存四份 top32，另外 555460 个位置仅有标量。top32 已核形状、有限值和 token ID 范围，不能用它重建全词表 KL。

确定性选中的两个位置保留八个 FP32 全词表数组，共 4862976 字节，数组 payload 全有限并完成成员 SHA 核验；这不等于对全词表概率归一化或 KL 的重新计算，也不代表七组共享 24 GiB 总账已验收。教师自主生成与训练时固定学生历史上的教师分布分开保存；教师案例不加入训练或验证的分母。

可公开计数及原始证据摘要 SHA 保存在 `experiments/search_e1/reports/M-ten-outer-recorded-debug-20261009/summary.json`。原始题目、检索内容、token 明细和权重仅保留在私有实验输出与持久本地备份中。当前结论仅覆盖 M；完整七组、70 轮与 5632 个正式评测槽位仍未完成。
