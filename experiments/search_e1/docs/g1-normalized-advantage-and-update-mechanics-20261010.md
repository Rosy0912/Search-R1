## 实测结论及边界

对同一批 Search-G1 轨迹分别用 strict correctness C 和重构 shaped reward R 计算组优势。两个独立远端 CPU 读取都真实 exit0，聚合输出逐字节一致；原输入完整文件 SHA、当前原 GRPO 源文件 SHA 和函数 AST 均核验通过。计算使用 binary64 数学参考，不是重放历史 Torch FP32 优势或真实训练梯度；R 是冻结规则重构，不宣称历史逐行 bitwise。Mac 只收到此类小型聚合结果，原轨迹/奖励行/张量留远端。

每个非零方差组：

\[
A_i=(R_i-\bar R)/(s+10^{-6}),\quad
\operatorname{mean}(A)=0,\quad
\operatorname{Var}_{sample}(A)=(s/(s+10^{-6}))^2.
\]

样本标准差分母为 G−1；G=5 时组内总体方差是上述值的4/5，零方差组优势为0。相同均值和方差不意味着轨迹优势向量、排序或更新方向相同。

## 当前前向、反向及两种 loss

当前已核 Search-G1 配置为512题×5轨迹=2560，global mini128，4 ranks/local mini32，physical micro2，16次梯度累积，ppo_epochs1。通常每外层20个 Adam 更新机会；安全拒绝时不能报20次成功写入。

训练使用已生成的完整序列作 causal teacher forcing，一次 micro 前向产生全部响应位置 logits，并 gather 实际 token 概率，再 backward。它不在 backward 前重新逐词采样。旧行为概率、原组优势在本 outer 固定，新的 student 参数随每 mini 的实际 Adam 改变。现有损失采用 micro 内有效 token mean，不是每条轨迹先平均。

自信度需要：

\[
\ell_i=-\sum_t M_{it}\log\mu(a_{it}\mid H_{it})/\sum_tM_{it}.
\]

最终 PG loss 已含有带正负号的 A、概率比和 clip，因此不能拿其标量当自信度。完整 policy loss 可以另含 reference KL/entropy；当前已核 common8 recipe 的两个系数均为0，不能说当前有非零 KL 项。当前实现已有 `sampling_log_probs`/`old_log_probs` 与对应真实 mask。复用它求每轨迹负均值，不新增模型前向；它是采样分布 μ 的行为 NLL，不静默称未经处理模型 π 的 NLL。新增 EMA/CDF/exp 为小型统计计算，实际增量时间尚未测量。
