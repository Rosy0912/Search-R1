# OPSD 效果、loss 与逐轮 TRAIN EM：当前已验快照

**目前 P 与 J 在同协议 BF16 下并列第一，均为 242/512（47.265625%）；共同基线是 239/512（46.6796875%）。** 两者各净增 3 题（+0.5859375 pp），但点估计领先还不等于稳定收益。P 的 paired bootstrap 95% 区间为 [−1.56, +2.73] pp，跨 0；J 的配对区间仍待最终统计，不能复用 P 的区间。

C0 最低。降低学习率的 C1 比 C0 多答对 9 题，但该差值的 95% 区间 [−0.78, +4.49] pp 也跨 0。P 比 C1 多 6 题，区间 [−0.78, +3.32] pp 同样跨 0。J 也比 C1 多 6 题，但其独立置信区间尚未产出。J 相对基线的 3 题净增全部来自 NQ；P 则来自 NQ 1 题、Hotpot 2 题。并列总分不等于逐题行为相同，也不能宣布某改动已确定修复退化。

FP16 部署另比较：FP16 基线和 P 都是 **245/512（47.85%）**，净变化为 0。这里的 FP16 部署还包含 CPU 合并后转换，不能把它与 BF16 未合并模型的差值全归因于数值 dtype。J FP16 仍在运行。

## loss 第一轮到第十轮

采用原生 `weighted_post_loss`，即每轨迹有效 token 均值乘其权重后、按真实轨迹数平均的裁剪目标。

| 组 | 第1轮 loss | 第10轮 loss | 相对变化 |
| --- | ---: | ---: | ---: |
| C0 | 0.393250 | 0.339097 | -13.77% |
| C1 | 0.394526 | 0.395478 | +0.24% |
| M | 0.006589 | 0.006513 | -1.16% |
| R | 0.480306 | 0.512258 | +6.65% |
| W | 0.536008 | 0.555789 | +3.69% |
| P | 0.463870 | 0.448477 | -3.32% |
| J | 0.006670 | 0.005948 | -10.83% |

C0 的 loss 降了 13.77%，但固定验证最差，说明目标分布匹配得更好不等于回答更正确。M/J 含 90% 冻结 outer-old 的混合目标；W/J 另加 reward 权重，且各轮使用新轨迹。因此这些 loss 的绝对大小、跨组排名和首末变化不能直接解释成能力优劣，也不是在共同固定响应上重算的学习曲线。
