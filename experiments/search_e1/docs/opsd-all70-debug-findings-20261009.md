# 七组70轮 OPSD：已核记录、分布冲突与仍缺的效果结论

七组 C0/C1/M/R/W/P/J 的训练均已完成十个 online outer。全70轮原生链汇总为699次已提交 Adam、21,132条可用轨迹曝光、4,060,515条有效 token。HKUST CPU 读者实际完成且等待退出码0，原生 token 标量、mask、顺序、尾批实际分母和记录的 loss 对账通过。这说明训练与这些已记录数值可追溯，尚不等于全部11权重的效果评测或全部 debug 验收完成。

J 的独立 final100 读取也通过：八 rank 的真实 Adam100完整状态一致，504个 FP32 adapter tensor 全有限、相对共同初始权重全部改变，RNG/scaler/cursor绑定有效，CPU读取没有初始化CUDA。最后明确的评测快照仍是 J 的512评测 RUNNING、仅11条已生成，不能给出J最终EM或J_fp16结果；原driver继续自动执行，未重复训练。

## 数据支持什么

触发 reverse 词表分量上限10的位置很少，但学生与教师在这些位置的分布冲突很强。五个非混合目标组的触发位置比例为0.175%–0.359%；在同一触发词表集合上，学生平均概率质量约0.85–0.89，教师约3.5×10⁻⁶–4.4×10⁻⁶。可以据此定位“学生很倾向、教师很排斥”的上下文，不能直接认定教师错、学生对，或者这种冲突就是EM变化的原因。

M和J都使用0.1教师＋0.9冻结outer-old的混合目标，全部有效 token 中均没有触发裁剪。M的raw/post等轨迹loss同为0.006581888019591935，J同为0.006350629759556914；J覆盖527,984个有效 token。它们与纯教师目标组的loss不是同一个对象，支持的是“锚定改变了目标及实际冲突程度”，不是“教师纠错更可靠”或“效果已改善”。M现有固定512为237题、C1为236题，不能以净1题说明混合目标的可靠收益；J尚缺最终评测。

P的触发比例更高，但其同协议BF16固定512为242题、C1为236题，相关配对区间跨0；不能把较多裁剪自动解释为退化，也不能把较小loss或零裁剪当成效果指标。各组后续在线轨迹、K和实际Adam数不同，P还包含精度和部署管线差异。此前九个已闭合权重的统计与限制见 [九权重评测报告](opsd-ablation-P-complete-nine-models-20261009.md)；这里不从训练聚合选择“赢家”。

## 保存覆盖与未核边界

已核4,060,515个有效token的标量记录；top32共573,440个位置（每组81,920），其余3,487,075个位置只有标量层。保存位置的四套独立长度32数组均检查有限值及ID范围，没有重新执行排名、归一化或模型logits；top32不能重建全词表KL。

完整词表保存为每组两个确定性预选有效位置×四分布，共56个FP32 NPY、34,040,832字节，shape均[151936]。实际成员SHA、payload有限和预选位置规则通过，七个已核子集没有cap-skip；这只证明所列56个已提交文件，不是全部token的全词表dump，也不是全部物理残留的清查。`debug-coverage-publication.json`仍明确 `all70_debug_coverage_complete=false` 和 `shared_24GiB_ledger_complete=false`：全局24GiB共享账本、额度reservation、未提交/失败/重试残留的实际物理集合仍待闭合。

自主特权教师为每组80例、合计560例，排除训练和验证分母。案例/HTTP及嵌入的parent rc0/release已检查，但该coverage reader没有独立读取外部teacher phase-exit完成终态证明。教师自己的生成历史不是训练固定D-history中的teacher-forced q。学生每组25,600原生生成行、80个generation文件和80个HTTP文件已按源member SHA持久保存；此次reader没有重新解析全部学生文本或新增QA语义评分。

实际dtype执行、全部失败/overflow重试历史和共享空间账本需要单列。相应CPU helper已发布至79972ed，但连接超时使新部署尚未开始，不能说它们已完成，也不能把SSH连接超时当成Node训练失败。已经完成的final J数值读取与现有记录检查仍有效；不为连接问题重跑J或热改冻结科学源码。

## 效果归因仍须完成什么

训练70轮和记录对账已经完成，整个目标仍未完成。还需J/J_fp16各512真正结束、全11权重5632条正式预测完整唯一覆盖及原controller/driver实际wait0与自有后代释放，再统一18项对照×整体/NQ/Hotpot共54分层、问题配对bootstrap和严格协议/搜索失败分析。需要给出LR、混合、随机D、权重、精度及J组合分别支持/削弱/未知的结论，并单列实际K/Adam/曝光差异。还需完成新CPU precision/失败历史及共享词表物理账本，不能把56个已核NPY当作全账本完成。固定十轮末端评测也不能插值精确退化发生步。
