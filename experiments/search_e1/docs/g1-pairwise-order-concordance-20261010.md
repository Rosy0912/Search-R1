# Search-G1 原始正确性与探针奖励的逐对排序核验

2026-10-10，北京时间。主指标采用用户要求：C1>C2 时，R1 是否也大于 R2。这里 C 是同一原始轨迹的严格正确性 0/1，非法输出计 0；R 是已验收的历史奖励重构值 R_reconstructed，不是假称保存过的原在线逐条奖励。

## 定义与样本

只比较同一次迭代、同一道题原五条 sibling 轨迹的无序对 i<j。每组共有10对；若 k 条正确，C 不同的可比较对为 k(5−k)。

\[
S=\frac{\sum_{g}\sum_{i<j}\mathbf1[(C_{gi}-C_{gj})(R_{gi}-R_{gj})>0]}
{\sum_{g}\sum_{i<j}\mathbf1[C_{gi}\ne C_{gj}]}.
\]

C 不同而 R 打平计严格失败；C 相同的对不进入主指标分母，单独列为双方并列或仅 C 并列。C 全相同的组主指标未定义，不把其计为成功、失败或零。合并指标先累计整数对数再相除，不先计算迭代均值或组均值。

范围为1、20、40、60、80、100、120、140八个保存点，每点512题×5轨迹，合计20,480轨迹、4,096原组、40,960同题配对；不是1–150全迭代。该组身份、完整分片覆盖和同源C/R匹配已验收。

40,960对完整互斥分解：同序4,758；反序0；仅R并列0；仅C并列13,464；双方并列22,738。仅C并列占全部配对32.8711%，占全部C并列对37.1913%。这些对不是用户严格不等式要求的反例。

Kendall τ-b是另一个、对并列敏感的定义：令P/Q为同序/反序，T_C/T_R为仅C/仅R并列，则 τ-b=(P−Q)/sqrt((P+Q+T_C)(P+Q+T_R))。它小于1是因为C并列被R区分，并非出现正确/错误反序；不能据此宣称精确退化时刻或有害因果。τ-b不能替换用户所定义的严格一致率。

辅助跨题检查：合并6,994条正确与13,486条错误/非法轨迹，94,321,084个正确–错误跨题对全部同序，AUROC=1。通过排序奖励桶计算，不枚举所有对；跨题/跨保存点混合不同于主指标的同题比较。

## 为什么100%仍不能说明探针的新增排序有效

该实现正确奖励至少0.98，错误/非法奖励最多0.05，跨正确性排序由奖励门控结构保证。主指标实际通过了这个要求，但无法评价同为正确或同为错误时，b/d导出的额外偏好是否合理，也不等价于奖励线性成正比。

GRPO使用组内(R−mean)/(std+epsilon)。它的相对更新方向还受同C轨迹之间的奖励差别影响。额外核查984个混合C组、2,344条正确轨迹：其中仅1条（iter20）R低于其组R均值，差值严格大于1e-4；2,343条高于，无等于。C中心化下这2,344条本应全部正值。这证明“跨正确性排序完全一致”不保证所有正确轨迹的组相对奖励均为正；但1/2,344不能夸大为主要退化机制。这里只重算记录数值，没有重放原native Torch advantage或实际梯度。

更大范围的新增信号是13,464个C并列但R不同的配对，以及已核出的1,256个C全相同而R有差异的组。是否有益需联系组归一化、b/d与实际生成表现，不能只凭100%排序一致率、Pearson或τ-b判定探针是否被利用或训练退化因果。
