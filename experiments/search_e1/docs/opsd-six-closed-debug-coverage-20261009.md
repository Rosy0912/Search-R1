# 六个已闭合 OPSD 组：实际 debug 覆盖与裁剪分布冲突

本次已核对 C0、C1、M、R、W、P 的 60/70 个 online outer：599 次已提交 Adam、18,120 条可用轨迹曝光、3,532,531 条有效 token 记录。训练原生 mask、顺序、真实尾批分母及记录的 loss 重构均通过，检查到的标量全有限。它们是六组各自实际在线采样后的记录，不是相同固定轨迹，也不是固定验证集曲线。J 已完成十轮并进入评估，但尚未并入本次六组 debug 统计；下列数值不会随 J 的实时进度自动改变。

## 新的分析结论与边界

触发词表分量上限 10 的 token 位置很少：五个未混合目标组为 0.175%–0.359%。但这些位置存在很强的分布冲突：在同一触发词表集合上，学生平均概率质量约 0.85–0.89，教师约 3.5×10⁻⁶–4.4×10⁻⁶。这表明学生很倾向的一组 token 被教师赋予极低概率，值得回到保留的上下文和轨迹分析。它没有判断哪一方的事实答案正确，也没有证明这些位置导致 EM 变化；仅靠该概率质量无法给出教学纠错是否有效的因果结论。

M 使用 0.1 教师＋0.9 冻结 outer-old 的混合目标，其 637,380 个有效位置没有触发裁剪，目标 loss 也明显更小。这支持“锚定改变了训练目标及其冲突程度”，不能把混合目标 loss 当成纯教师 KL，更不能据此称性能提升。同协议固定512中 M 为237题、C1为236题，净差只有1题，仍需结合配对区间和其他组判断。

P 的触发比例比 C1 高，但固定 BF16 512 为242题、C1为236题，相关区间跨0。因此裁剪更多不能直接解释为退化，裁剪更少也不是可靠效果指标。P、C1 的后续在线轨迹及实际曝光不同，P 的计算与部署管线还包含精度差异，不能仅凭这张表把差异归因于 dtype。已闭合512的完整配对边界见 [九权重评测报告](opsd-ablation-P-complete-nine-models-20261009.md)。

## 记录实际保存到了什么程度

- 标量层：3,532,531 个有效 token 的原生记录已核对，记录的 mask、顺序和真实 batch/tail 分母一致；没有重新运行模型、恢复 RNG、重算 logits 或梯度。
- top32 层：每组81,920个位置，总计491,520个位置。每个位置的四套独立数组都检查了长度32、有限值、ID范围和唯一性；其余3,041,011个位置仅有标量层记录。本次没有重新执行 top32 选择排序或概率归一化，top32 不能重建完整词表 KL。
- 完整词表层：每组两个预选有效位置，每位置四个 FP32 分布，合计48个 NPY、29,177,856字节，shape均为[151936]。实际 payload 全有限、member SHA 重新读取、预选规则与首两个有效位置一致。六组没有 cap-skip；这不是“所有 token 的词表分布都已保存”。全七组共享24GiB账本、保留额度和未提交残留仍待最终闭合，本次仅接受六组已保存子集。
- 自主教师层：每组80个实际特权 teacher 生成案例，共480个，不计入训练或验证分母。解析的案例/HTTP与嵌入的 parent rc0/release一致，但本次 coverage reader 没有独立读取外部 teacher phase-exit 作为终态证明。自主 teacher 的历史也不等同于训练固定 D-history 条件下的 teacher-forced q。
- 学生轨迹层：每组十轮共25,600条原生行，80个 generation trace及80个 HTTP trace文件已通过源文件 SHA 绑定保存。本次读者没有重新解析这些学生完整文本，不能把保存验收说成新增语义评分。
