# H100 经 HF 迁移至 HPC3

默认按用户指定的数据路线执行：**H100 → mgmt-host → HF → HKUST2 → HKUST3 → HPC3 共享存储**。Mac 是 SSH 控制端；本任务用户已明确禁止使用或改动 Mac 的代理。HF 下载须使用远端直连或用户授权的远端自身出口；Mac 不是模型/数据落盘站。不要把 Mac 直连 HPC3 当作默认数据路线。

## 开始前

先读最新人工指令和当前任务状态。使用原始人工指令时间判断冲突，不让旧 heartbeat/摘要回放覆盖后来的明确授权。该 skill 记录迁移方法，不自动授权其他仓库、集群、资产或训练。

- 建立/修复连接、核实各跳身份与空间：读 [连接与存储](references/topology.md)。
- 执行上传、hfd 下载、中转、恢复及验收：读 [迁移操作](references/workflow.md)。
- 继续 TOP-D 2026-10-09 任务或复用已部署代码：读 [已验证案例和源码](references/topd-20261009.md)。案例里的 PID、速度和容量只是历史证据，每次重新查询。

在继续任务时，先检查 controller、锁、真实进程身份、progress、failures、各组 SHA 回执和 complete。不要重复启动已有上传器、下载器或目标写入器。用户问进度、提出加速或批评不等于取消迁移。

## 必须保持的资产与凭据约束

1. 模型/数据只落盘 H100、已授权 HF 仓库、已核实的 HKUST 中转盘和 HPC3 共享目标。mgmt-host/Mac 仅进行有界内存流转；本任务不使用通用“下载失败就本地落盘”回退。
2. 沿用已有 SSH 身份和严格主机密钥校验，不复制私钥，不打印 token，不保存 token 到脚本、命令参数、URL、下载清单、日志、automation 或 Git。通过 stdin/进程 RAM 传递凭据；公共配置与 manifest 可落盘。
3. 校园 SSH 默认直连；公网 HF 只测试直连和远端自身出口，禁止回退 Mac 代理。二者分开配置，不能把 HTTP 代理必要性推成校园 SSH 也要 SOCKS。
4. 每个目标归档只能有一个写入者。新增下载路线按组分工；发现原进程写同一组时，等待其结束或在确认归属后协调交接。保留旧部分文件和已校验文件。
5. 不删除源资产、不停止外来进程、不重启训练、不自动申请 GPU。只修复明确属于本次迁移且已失败或无进展的组件；正常有增量的进程不打断。

## 执行顺序与完成条件

源端先生成归档、归档 SHA256、所有原始文件的 path/size/SHA256 和来源记录。mgmt-host 从源读取内存流提交私有 HF，逐组记录 commit，并用 HF 官方 paths-info 的 LFS SHA/大小对源复核。全部计划上传验收后推进 HF 下载；已运行任务沿用用户后来明确接受的并行分工。

下载端先核实真实可写挂载和空间。比较官方/镜像、直连/代理；用同一个真实私有归档和相同字节区间测速。hfd 可使用 aria2 多连接，但须先处理 token 落盘和稀疏文件进度问题。下载通过源/HF SHA 后，按默认链路 HKUST2→HKUST3→HPC3 逐跳续传。rclone 可用于已验证认证的 SFTP 路线；不因为 TCP22 可达就声称认证和传输已可用。

**只有以下全部通过才能宣告迁移完成：**

- 每组源、HF、HKUST2、HKUST3、HPC3 的归档 SHA/大小一致；若用户明确授权省略某中转跳，记录实际路线和相应验收，不伪造该跳回执。
- HPC3 解包的每个原始文件 SHA/大小与源 manifest 一致。
- 再次 fresh 读取目标共享存储全部选定文件并验 SHA；检查源是否新增必要的真实 checkpoint，若有则补入计划。
- 目标实际 complete.json 的状态为 `MIGRATION_ALL_SELECTED_ASSETS_VERIFIED`。仅 HF 已上传、下载完成、hfd Done 或字节达100%都不够。

完成后保存状态、报告和镜像，告知完整 HPC3 路径及核验范围；若用户要求完成后关闭巡检，再停用该迁移 automation。源码及恢复入口变化及时提交、推送并核验远程 SHA；不提交凭据、模型或环境。

## 巡检报告

用户要求定期可见进度时，每轮完成后报告：目标实际压缩 GB/计划总 GB、百分比、teacher **已 SHA 校验**片数/总片数、本轮实际字节增量÷实际时间间隔的平均 MB/s、错误/重试状态。HF/HKUST 下载进度另列，不混进 HPC3 目标数字。

读取失败则标注“上次实测”、时间和失败原因，当前速度写“无法计算”；不能冒称0速或当前数值。aria2 使用 RPC `completedLength`，不能把稀疏文件 stat 大小当已下载量。正常无新增错误的历史重试与本轮新增失败分开报告。
