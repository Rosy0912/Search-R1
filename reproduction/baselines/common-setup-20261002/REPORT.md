The selector verifies split output hashes, candidate HF hashes, actual weights and shards, tokenizer vocabulary/BOS/EOS, changed student weights; highest F1 wins, ties earliest update. It never reads final-test question data for ranking. Original final/periodic inputs are read only to exclude overlap when defining the split.
